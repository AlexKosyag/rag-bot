# Интерфейс: Streamlit-чат и админка

Единое приложение `app.py` с двумя страницами (sidebar-навигация).

## 1. Чат (`src/ui/chat.py`)

### Экран

```
┌─────────────────────────────────────────────┐
│ 💬 Чат                                     │
│                                             │
│ Вы: Какой порядок согласования отпуска?     │
│                                             │
│ 🤖 Порядок: ... 1) ... 2) ...              │
│    📎 Источники (2) ▾                       │
│       • отпускной-регламент.md — п.4.2,     │
│         score 0.81                          │
│       • hr-инструкция.docx — стр. 3,        │
│         score 0.74                          │
│                                             │
│ Вы: А quota на Марс?                        │
│ 🤖 Нет в документах.                        │
│    🔍 Показать найденные фрагменты ▾        │
├─────────────────────────────────────────────┤
│ [сообщение...]              [Отправить ➤]  │
└─────────────────────────────────────────────┘
```

### Поведение

| Элемент | Реализация |
|---|---|
| История | `st.session_state.messages`, очищается кнопкой «Новый диалог» |
| Стриминг | `st.write_stream` — первый токен виден сразу |
| Источники | `st.expander`: имя документа, заголовок/страница, score, превью чанка |
| Отказ | «Нет в документах» + экспандер с найденными фрагментами (чтобы пользователь видел, что база пуста, а не сломана) |
| Ошибки LLM | понятное сообщение «Модель недоступна (Ollama на localhost:11434). Проверьте `ollama serve`» |
| Строка состояния | индикатор: модель, `top_k`, порог — видно, чем отвечает бот |
| Инжекции | вопросы с «игнорируй инструкции» обрабатываются промптом (см. [pipeline.md](pipeline.md)) |

Формат ответа: Markdown (списки, шаги) — регламенты хорошо читаются структурой.

## 2. Админка (`src/ui/admin.py`)

### Вкладка «Документы»
- Загрузка файлов (`st.file_uploader`, множественный выбор PDF/DOCX/MD).
- Таблица реестра: имя, статус (`pending / indexing / ready / error`), чанков, дата, sha256-метка.
- Действия: **Переиндексировать**, **Удалить** (с подтверждением — чанки удаляются из Chroma).
- Ошибки парсинга — текстом в строке (например, «PDF без текстового слоя — скан не поддерживается»).
- Дубликат по sha256 → сообщение «файл уже индексирован».

### Вкладка «Параметры»
| Параметр | Диапазон по умолчанию | Эффект |
|---|---|---|
| `top_k` | slider 3–10, default 5 | больше контекста → выше Recall, дольше генерация |
| Порог отказа `τ` | slider 0.0–1.0, default 0.55 | выше → больше отказов и меньше ложных ответов |
| Модель LLM | selectbox: qwen2.5:7b / qwen2.5:3b / API | требует переключения на стороне конфига, отражается в статусе |
| Эмбеддинг | e5-base / MiniLM (light) | переключение требует полной переиндексации |

- Кнопка **«Сохранить в конфиг»** — записывает значения в `config.yaml`;
  без неё изменения действуют в текущей сессии.
- Предупреждение при смене embedding-модели: «Требуется полная переиндексация».

### Вкладка «Метрики»
- Таблица последнего запуска `src.evaluate` (Hit@k, Faithfulness, refusal, p50).
- Кнопка **«Запустить оценку»** (фоновый поток через `st.spinner`; eval можно и из CLI).
- Графики matplotlib: кривая Correct/False Refusal от `τ`.

## 3. Нефункциональные требования UI

- Модель эмбеддингов и Chroma-клиент — `@st.cache_resource` (грузятся один раз).
- Загрузка/индексация — прогресс-бар (`st.progress`) и статус в реестре.
- Админка доступна без авторизации (учебный проект), но помечена в README как
  «для администратора»; опционально — простой пароль через `ADMIN_PASSWORD` в `.env`.
- Вёрстка: стандартный Streamlit, без кастомных CSS-зависимостей — воспроизводимо на любой машине.
