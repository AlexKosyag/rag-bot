# Документация проекта «RAG-чат-бот по внутренним документам»

Чат-бот на базе RAG, отвечающий на вопросы сотрудников **только** по загруженной базе
документов (регламенты, инструкции, FAQ), со ссылками на источники и корректным отказом
«Нет в документах», если ответа в базе нет.

## Модели и ключевые технологии (зафиксированы)

| Роль | Модель / технология |
|---|---|
| Эмбеддинги (основная) | `intfloat/multilingual-e5-base` (768-dim, окно 512 токенов) |
| Эмбеддинги (лёгкая, fallback) | `sentence-transformers/multilingual-MiniLM-L12-v2` (384-dim, окно **128** токенов) |
| Генерация ответов | `Qwen2.5-7B-Instruct` (через Ollama), fallback: `qwen2.5:3b` / OpenAI-совместимый API |
| Векторное хранилище | **ChromaDB** (embedded, персистентная) — *замена PostgreSQL + pgvector* |
| Интерфейс | Streamlit (чат + админка) |
| Оценка качества | MRR / Hit@k / Context Recall + LLM-as-judge (Faithfulness, Answer Relevancy) |

Обоснование выбора — в [stack.md](stack.md).
