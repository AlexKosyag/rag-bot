# ГОСТ 2.104-2006. ЕСКД. Основные надписи

**Технический регламент (выдержка)**
**Дата введения:** 2007-01-01
**Статус:** действующий

## 1. Область применения

Настоящий стандарт устанавливает состав и правила заполнения основных надписей на конструкторских документах. Стандарт распространяется на документы, выпускаемые в системе ЕСКД.

## 2. Состав основных надписи

Основная надпись включает следующие графы:

| Графа | Наименование | Пример заполнения |
|---|---|---|
| 1 | Наименование документа | Вал приводной |
| 2 | Обозначение документа | ТМИ-102345-03-01 |
| 3 | Литера | Р (рабочий) |
| 14 | Стадия | Р3 |
| 18 | Разработал (подпись, дата) | Иванов И.И. 12.04.2024 |
| 19 | Проверил (подпись, дата) | Петров П.П. 13.04.2024 |
| 22 | Утвердил (подпись, дата) | Сидоров С.С. 15.04.2024 |

## 3. Требования к заполнению

1. Наименование документа записывается без сокращений, с указанием типа документа (чертёж, спецификация, схема).
2. Обозначение документа присваивается по правилам, установленным главным конструктором.
3. Дата записывается в формате ДД.ММ.ГГГГ.
4. Подпись ставится только на оригинале. Копии заверяются штампом «Копия верна».

## 4. Место расположения

Основная надпись размещается в правом нижнем углу листа. При оформлении документов на нескольких листах основная надпись ставится на каждом листе.

## 5. Форма основной надписи

Форма 1 (основная) — размер 185×55 мм.
Форма 2 (для документации на несколько листов) — размер 185×55 мм с дополнительной графой «Лист / Листов».

## 6. Дополнительные надписи

Допускается размещение дополнительных надписей: ведомость покупных изделий, отметки о консервации, шифры по заказу. Дополнительные надписи не должны перекрывать основные графы.
