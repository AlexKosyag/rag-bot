# Стандарт предприятия: порядок документооборота

**Организация:** АО «Техномаш-Инжиниринг»
**Номер:** СТ-2024-000

## 1. Общие положения

Стандарт СТ-2024-000 устанавливает единый порядок для АО «Техномаш-Инжиниринг». Утверждён главным инженером, обязателен для всех подразделений.

## 2. Основные требования

Срок хранения документов — 5 лет. Ответственное лицо — начальник канцелярии.
Срок исполнения по документам стандартов — 5 рабочих дней. Контроль — служба качества.
Все записи оформляются по формам приложений к настоящему стандарту СТ-2024-000; вольные формулировки не допускаются.

## 3. Порядок применения

Стандарт вводится в действие приказом. Изменения оформляются листом изменений с визой главного инженера.
Проверка знания стандарта — при аттестации персонала, не реже одного раза в 3 года.
