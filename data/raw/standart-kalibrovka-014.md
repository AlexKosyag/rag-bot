# Стандарт предприятия: калибровка оснастки

**Организация:** АО «Техномаш-Инжиниринг»
**Номер:** СТ-2026-014

## 1. Общие положения

Стандарт СТ-2026-014 устанавливает единый порядок для АО «Техномаш-Инжиниринг». Утверждён главным инженером, обязателен для всех подразделений.

## 2. Основные требования

Срок хранения документов — 7 лет. Ответственное лицо — начальник канцелярии.
Срок исполнения по документам стандартов — 5 рабочих дней. Контроль — служба качества.
Все записи оформляются по формам приложений к настоящему стандарту СТ-2026-014; вольные формулировки не допускаются.

## 3. Порядок применения

Стандарт вводится в действие приказом. Изменения оформляются листом изменений с визой главного инженера.
Проверка знания стандарта — при аттестации персонала, не реже одного раза в 4 года.
